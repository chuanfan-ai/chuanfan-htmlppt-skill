# 风格 C · 船帆大会培训

风格 C 是独立、可直接使用的 HTMLPPT 风格，模板为 `assets/template-conference.html`。它服务于大会分享、学校/企业培训、AI 方法教学、工具教程、案例讲解和长篇现场演示。

## 1. 视觉定位

关键词：清晰、现代、现场可读、浅色主导、蓝橙语义、大标题、证据素材、少量深色舞台页。

- 默认品牌依据：`references/chuanfan-brand.md`。
- 默认内容忠实依据：`references/feishu-content-contract.md`。
- 编辑与用户修改保护：`references/local-editor-contract.md`。
- 模板已经内置完整编辑器，不需要借用其他 PPT Skill。

## 2. 选择条件

优先使用风格 C：

- 中文长篇培训或大会演讲。
- 内容含截图、提示词、流程、案例图片、二维码或视频。
- 需要观众快速抓住结论，同时保留真实证据。
- 船帆本人使用且没有指定其他风格。

不优先使用风格 C：

- 用户明确要电子杂志或瑞士国际主义。
- 内容是纯历史叙事、电影化发布会或极简奢侈品牌，需要另一套视觉语言。
- 客户提供了必须严格执行的 VI/KV；此时保留结构方法，但覆盖品牌色与字体。

## 3. 明暗自适应

长培训通常从 70%–90% 浅色开始，但按内容任务调整，不能把比例当机械指标。

| 页面任务 | 默认明暗 | 理由 |
|---|---|---|
| 封面 | 浅色分屏或深色舞台 | 建立主题与身份 |
| 背景解释、教学正文 | 浅色 | 长时间观看更稳定 |
| 截图、提示词、流程、表格 | 浅色 | 保证文字和证据清晰 |
| 案例图片、案例视频 | 浅色展台或局部深色媒体区 | 突出素材，不吞掉说明 |
| 关键判断、章节转场、金句 | 深色 | 制造停顿和节奏 |
| 行动页、二维码、反馈 | 浅色 | 扫码、链接和步骤更易用 |

节奏要求：

- 连续 5 页以上深色通常是错误信号。
- 深色页前后应有浅色缓冲，除非是明确的短章节。
- 深浅切换必须能用页面任务解释，不能只为“看起来高级”。

## 4. 品牌颜色

从 `chuanfan-brand.md` 读取最新变量。当前默认：

```css
--cf-white: #ffffff;
--cf-black: #090909;
--cf-blue: #1677ff;
--cf-blue-deep: #0a48c7;
--cf-blue-soft: #eaf1ff;
--cf-orange: #ff7a00;
--cf-orange-soft: #fff0e9;
--cf-gray-50: #f7f7f7;
--cf-gray-600: #525252;
--cf-line: #d9d9d9;
```

语义：黑色是结论，蓝色是 AI 能力与方法，橙色是行动与转折。每页通常一个主强调色，橙色面积小于蓝色。

## 5. 字体与安全区

- 中文标题与正文使用 `Inter, PingFang SC, Microsoft YaHei, Arial, sans-serif`。
- 标题推荐 48–108px；封面可更大，但必须实测不溢出。
- 正文推荐 24–36px；辅助信息不低于 18px。
- 主体安全区：左右 6%–8%，顶部 6%–9%，底部给页码与进度留出至少 6%。
- 左上角栏目标签与大标题不能重叠；右上角说明与导航按钮必须分别留出空间。
- 任何字号都以真实浏览器截图为准，不只看 CSS 数值。

## 6. 页面配方

模板已提供以下可复用类；生成前先读取模板 CSS，不能臆造类名。

1. `cf-cover`：浅色主标题 + 深色信息侧栏。
2. `cf-split`：左结论、右证据或媒体。
3. `cf-stage`：深色关键判断或章节转场。
4. `cf-card-grid`：2–4 个能力、步骤或对比卡片。
5. `cf-prompt`：浅色解释列 + 深色逐字提示词框。
6. `cf-steps`：连续步骤、箭头或流程。
7. `cf-quote`：一句金句 + 小号解释。
8. `cf-case`：案例名称、金句、图片/视频和迁移任务。
9. `cf-link-card`：二维码 + 可点击文字链接 + 行动说明。

一套长 deck 至少交替使用 4 类页面配方；连续页面不要只是换文字不换结构。

## 7. 素材作为主体

- 用户截图、海报、二维码、文档图片和视频是证据，不拿来做模糊背景。
- 证据素材默认 `object-fit: contain`，保持源比例。
- 专门生成的装饰图或背景图可按槽位 `cover`。
- 图片与视频旁边只保留对理解有价值的标题、金句、观看任务或迁移启发。
- 案例页优先同页呈现“案例名称 + 金句 + 视频/图片”，真实画布放不下时再拆页。

## 8. 飞书内容模式

船帆本人给出飞书文档时，默认启用 `feishu-content-contract.md`：

- 内容与顺序跟随飞书原文。
- 内容尽可能全部保留，主要进行视觉重构。
- 提示词、代码、JSON、命令和参数逐字保留。
- 原文链接变为可点击 `<a target="_blank" rel="noopener noreferrer">`。
- 页面使用 `data-source-order` 与 `data-verbatim-id`，并通过校验脚本验收。

## 9. 编辑器关系

风格 C 只规定内容和视觉。页面完成后必须调用独立 `htmlppt-interaction-editor` Skill 安装通用演示、编辑、保存和恢复能力。

模板内带 `HTMLPPT_EDITOR_CORE_*` 标记的核心只用于旧项目兼容；新安装器会从产物中移除它们，避免双工具栏。交互规则与模板旧代码冲突时，以独立 Skill 为准。

## 10. 禁止项

- 全套深色、蓝紫渐变、满页发光、赛博霓虹。
- 三个等宽空白卡片占满页面却没有信息密度。
- 左上角栏目标签压住大标题，右上角说明压住导航。
- 截图当背景、提示词缺字、链接不可点、视频比例失真。
- 用制作说明替代观众 takeaway，例如“这页放视频”“原文保留”。
- 页面留白只是因为内容没排好，而不是有意的视觉停顿。

## 11. 交付前验收

- [ ] 品牌变量与网站一致，或已记录客户品牌覆盖。
- [ ] 明暗选择能由页面任务解释，浅色承担主要教学内容。
- [ ] 左上、右上、底部页码和导航安全区没有压字。
- [ ] 提示词逐字校验通过，链接可以直接打开。
- [ ] 用户媒体按源比例显示，视频外框比例跟随元数据。
- [ ] 案例页同时表达证据和对教师/观众的迁移价值。
- [ ] 统一编辑器功能、历史语义和刷新恢复通过真实浏览器测试。
