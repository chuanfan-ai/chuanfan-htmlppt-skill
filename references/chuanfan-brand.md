# 船帆个人品牌视觉契约

本文件是风格 C 的默认品牌依据。除非用户明确指定客户品牌、活动主视觉或其他配色，否则按这里执行。

## 1. 品牌来源

基准网站：`https://www.chuanfanai.com/`

网站当前可核验的核心变量：

```css
:root {
  --cf-white: #ffffff;
  --cf-black: #090909;
  --cf-blue: #1677ff;
  --cf-blue-deep: #0a48c7;
  --cf-blue-soft: #eaf1ff;
  --cf-orange: #ff7a00;
  --cf-orange-soft: #fff0e9;
  --cf-gray-50: #f7f7f7;
  --cf-gray-100: #ededed;
  --cf-gray-400: #8a8a8a;
  --cf-gray-600: #525252;
  --cf-line: #d9d9d9;
  --cf-sans: Inter, "PingFang SC", "Microsoft YaHei", Arial, sans-serif;
  --cf-serif: Georgia, "Times New Roman", "Songti SC", serif;
}
```

网页改版后，先重新读取网站 CSS，再更新变量；不要凭印象换成相近颜色。

## 2. 颜色语义

- `#090909`：结论、主标题、深色舞台背景。
- `#1677ff`：AI 能力、方法、链接、结构主线、主行动。
- `#0a48c7`：蓝色在浅底上的深一级状态，或大面积蓝色块。
- `#ff7a00`：行动、转折、重点数字、警示性强调；面积必须小于蓝色。
- `#eaf1ff`：方法说明、步骤底色、轻量信息区。
- `#fff0e9`：行动提示、结果提醒、抽奖或限时任务。
- `#ffffff / #f7f7f7`：长培训的主背景。
- `#525252 / #8a8a8a / #d9d9d9`：正文次级层级、辅助信息和分隔线。

同一页通常只保留一个主强调色。蓝色与橙色可以同页出现，但必须分别承担“方法”和“行动”语义，不能作为随意装饰。

## 3. 明暗比例

- 长篇培训默认以浅色页面为主，常见起始范围是 70%–90% 浅色。
- 深色页用于封面、章节转场、关键判断、金句、案例聚焦和结束页。
- 截图、提示词、表格、流程和密集教学内容优先使用浅底。
- 不为追求“高级感”把整套做成深色，也不机械套固定明暗比例；每一页都要有内容理由。

## 4. 字体与构图

- 中文标题和正文默认使用无衬线字体。
- 大标题靠字号、字重、行距和留白建立大会感，不依赖渐变、发光或复杂阴影。
- 衬线字体仅作极少量英文编号、引语或编辑性点缀，不能成为整套中文正文体系。
- 优先使用清晰网格、细线、白边、黑色块、蓝橙强调和大面积留白。
- 圆角与胶囊可以使用，但只是组件语言；品牌识别的核心仍是颜色、排版和结构。

## 5. 禁止项

- 不把品牌蓝替换成泛紫、荧光青或低饱和灰蓝。
- 不使用大面积蓝橙渐变。
- 不让橙色成为整页主背景，除非用户明确要求活动视觉。
- 不使用通篇黑底、满页发光、赛博霓虹或“科技蓝渐变”代替品牌系统。
- 不为了统一视觉裁掉证据图片、二维码、截图文字或视频内容。

## 6. 用户或客户品牌覆盖

用户明确给出客户品牌色、活动 KV、学校 VI 或参考站点时：

1. 客户品牌优先于本文件。
2. 保留船帆品牌的结构方法，不强行保留蓝橙色。
3. 在项目 CSS 顶部记录覆盖后的变量和来源。
4. 编辑器工具栏仍使用稳定的高对比界面色，不与内容页品牌绑定。
